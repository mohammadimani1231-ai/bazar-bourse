# قوانین طراحی این پروژه (بازار بورس)

این فایل رو در ریشهٔ ریپازیتوری نگه دار — راهنمای دائمی هر تغییر UI/UX بعدی است. جزئیات کامل در `README.md` همین پکیج Handoff است؛ این فایل خلاصهٔ قوانینیه که نباید نقض بشن.

## قوانین سخت (هرگز نقض نشه)
- **تم پیش‌فرض روشن (light) است**، نه تیره. سوییچ به تاریک باید وجود داشته باشه ولی حالت اول باره روشنه.
- **RTL و فارسی** در کل رابط. جهت نوارهای پیشرفت/چارت‌ها باید از راست پر بشه، نه چپ.
- رنگ‌های `up` (سبز) و `down` (قرمز) **فقط** برای معنای رشد/افت قیمت یا خرید/فروش استفاده می‌شن. برای رنگ‌بندی دسته‌ای نمودارها (سری‌های غیرمعنایی) از پالت جدا (`series2`/`series3`) استفاده کن — هیچ‌وقت up/down رو به‌عنوان رنگ دلخواه برای چیز دیگه‌ای قرض نگیر.
- فونت متن فارسی: **Vazirmatn**. فونت همهٔ اعداد/قیمت‌ها/درصدها/ساعت‌ها: **JetBrains Mono** (مونواسپیس) — هیچ عددی نباید با فونت فارسی نمایش داده بشه.
- همهٔ ۹ صفحه (نمای کلی، سیگنال‌ها، اسکرینر، پرتفوی، کارنامهٔ عملکرد، نمای جهانی، گزارش‌ها، تنظیمات ریسک، سلامت) باید از یک سیستم طراحی واحد پیروی کنن — رنگ، تایپوگرافی، شعاع گوشه، فاصله‌گذاری، الگوی کارت یکسان.
- المان‌های تعاملی (دکمه، آیتم منو، ردیف جدول، اینپوت) باید hover/focus state داشته باشن.

## رنگ‌ها (oklch)
جدول کامل توکن‌ها در `README.md`. خلاصه: پس‌زمینه/متن با هیوی خنثی (۲۵۰)، accent برند آبی (هیو ۲۲۷، قابل تغییر)، up=سبز (هیو ۱۵۵)، down=قرمز (هیو ۲۷). هرگز رنگ‌ها رو دستی/رندوم انتخاب نکن — از فرمول‌های oklch مستند‌شده استفاده کن تا هارمونی حفظ بشه.

## قبل از هر تغییر بصری
1. `README.md` همین پوشه رو بخون.
2. `Dashboard.dc.html` رو در مرورگر باز کن و ببین.
3. اگه چیزی توی این فایل یا README مبهمه یا با ساختار فعلی کد در تعارضه، اول از کاربر بپرس — حدس نزن، چون تغییرات حدسی قبلی باعث نارضایتی کاربر شده.
